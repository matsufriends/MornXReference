# プライバシーポリシー / Privacy Policy

MornXReference は、利用者のデータを開発者や第三者のサーバーへ送信しません。

- 拡張が読み取るのは、利用者自身が X (x.com) 上で表示しているブックマーク一覧のページ内容だけです
- 各ポストの動画・画像の URL は、X が提供する公開の埋め込み用 API (`cdn.syndication.twimg.com`) から取得します。ログイン情報や Cookie は送信しません
- 取得した情報 (ポストの URL、作者名、本文、メディア URL) と表示設定は、利用者のブラウザ内 (`chrome.storage.local`) にのみ保存されます
- アクセス解析や広告は含みません

---

MornXReference does not send any user data to the developer or any third party.

- The extension only reads the bookmark list page that the user is viewing on X (x.com).
- Media URLs for each post are fetched from X's public embed API (`cdn.syndication.twimg.com`). No login credentials or cookies are sent.
- Fetched data (post URL, author, text, media URLs) and display settings are stored only in the user's browser (`chrome.storage.local`).
- No analytics or advertising is included.
