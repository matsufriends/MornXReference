# Chrome ウェブストア申請メモ

## 手順 (ユーザー作業)

1. https://chrome.google.com/webstore/devconsole を Google アカウントで開き、初回のみ開発者登録 (登録料 5 USD) を行う
2. 「新しいアイテム」→ `docs/store/MornXReference-<version>.zip` をアップロード (ZIP は `sh docs/package.sh` で作る)
3. 「ストアの掲載情報」に下記の文言と画像を入力
4. 「プライバシーへの取り組み」に下記の目的説明を入力し、プライバシーポリシー URL を設定
5. 「配布」で公開範囲を選び、審査に提出

## 掲載情報

- 名前: MornXReference
- 概要 (132 文字以内): X のブックマークの動画・画像をグリッドで眺める
- 詳細説明:

```
X (Twitter) のブックマークから動画・画像を集めて、X の画面内にグリッド状に並べて眺める拡張です。

・x.com の「ポストする」ボタンの下に「ギャラリー」ボタンが追加されます
・押すとブックマークを自動で読み込み、動画は自動再生、画像はそのまま正方形タイルで並びます
・タイルの大きさ、画像と動画の切り替え、文字や投稿日での絞り込みができます
・タイルをクリックすると拡大表示。元の投稿もすぐ開けます
・2 回目からは前回の一覧をすぐに表示し、増えた分だけを読み込みます

Live2D の WIP など「動いているものを一覧で見比べたい」用途向けに作りました。
データはブラウザ内にのみ保存され、外部には送信しません。
```

- カテゴリ: 生産性 (Productivity) など
- 言語: 日本語
- アイコン: `icons/icon128.png`
- スクリーンショット: `docs/store/screenshot-1.png` (1280x800)。追加する場合も同じサイズで
- プライバシーポリシー URL: https://github.com/matsufriends/MornXReference/blob/main/PRIVACY.md

## プライバシーへの取り組み (権限の目的説明)

- 単一目的: X のブックマークに含まれる動画・画像を、X の画面内にグリッド表示して閲覧する
- `storage`: 取得したメディア情報と表示設定をブラウザ内に保存し、次回の読み込みを速くするため
- ホスト権限 `https://cdn.syndication.twimg.com/*`: 各ポストの動画・画像 URL を X の公開埋め込み API から取得するため
- コンテンツスクリプト (`x.com`, `twitter.com`): ギャラリーボタンの設置、ブックマーク一覧の読み取り、ギャラリーの描画のため
- リモートコード: 使用しない
- データ使用: 個人情報・認証情報・ユーザーアクティビティ等の収集なし。「ユーザーデータを第三者に販売しない」「承認された用途以外に使用しない」「信用情報の判断に使用しない」の 3 項目すべてに同意する
