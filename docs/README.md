## 更新手順

1. [Chrome Developer Dashboard](https://chrome.google.com/webstore/devconsole) で既存のMornXReferenceを開く（初回だけ「新しいアイテム」を作成）。
2. パッケージを変更した場合は、「パッケージ」→「新しいパッケージをアップロード」から本体ZIPを送る。
3. 「ストアの掲載情報」に下記の詳細説明・アイコン・スクショ・サムネイルを設定する。
4. 「プライバシーへの取り組み」に下記の目的説明とプライバシーポリシーURLを設定する。
5. 配布設定を確認し、変更を審査に提出する。

**パッケージの概要・コード・同梱アイコンを変える場合**は、[manifest.json](../manifest.json) のバージョンを上げてZIPを作り直します。**詳細説明・掲載画像・プライバシーポリシーURLだけを変える場合**は、ZIPの再アップロードは不要です。[Google公式の更新手順](https://developer.chrome.com/docs/webstore/update)

## 掲載情報

- 名前: MornXReference
- カテゴリ: ツール（管理画面の選択肢に合わせる）
- 言語: 日本語
- パッケージの概要（`manifest.json` の `description`。管理画面では直接編集できません）:

```text
Xのブックマークを、画像・動画の一覧に。保存した参考資料をまとめて見比べられるChrome拡張です。
```

詳細説明（ストアの掲載情報に貼り付け）:

```text
保存した画像や動画を、ひとつずつ投稿を開かずに見返したい。
MornXReferenceは、Xのブックマークをギャラリー形式で表示する拡張機能です。

画像や動画が並ぶので、イラスト・アニメーション・デザインなどの参考資料を探したり、見比べたりするのに便利です。

・ブックマーク内の画像・動画をまとめて表示
・画面内の動画を自動再生
・表示サイズを自由に調整
・画像／動画、文字、投稿日で絞り込み
・クリックで拡大表示し、「元ポスト」から元の投稿へ移動

Xの左サイドバーに追加される「ギャラリー」ボタンから使えます。
```

スクリーンショットは、元の実画面の左サイドバーと上部操作欄を保持し、右側をサンプル画像と「元ポスト」リンクに差し替えています。

## プライバシーへの取り組み（権限の目的説明）

- 単一目的: Xのブックマークに含まれる動画・画像をグリッド表示して閲覧する。
- `storage`: 投稿URL、作者名、本文、メディアURL、表示設定をブラウザ内に保存し、次回の読み込みを速くするため。
- ホスト権限 `https://cdn.syndication.twimg.com/*`: 投稿IDを指定してXの公開埋め込みAPIから投稿情報・メディアURLを取得するため。画像・動画の表示時は配信元にも接続する。
- コンテンツスクリプト（`x.com`、`twitter.com`）: ギャラリーボタンの設置、ブックマーク一覧の読み取り、ギャラリーの描画のため。
- リモートコード: 使用しない。
- アクセス解析・広告・開発者独自サーバーへのデータ送信: 行わない。
