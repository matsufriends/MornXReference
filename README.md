# MornXReference

X (Twitter) の動画URLをグリッド状に自動再生して閲覧する Chrome 拡張。Live2D の WIP リファレンス用。

依存ライブラリ・ビルド工程なし。素の HTML/CSS/JS のみ。

## 読み込み手順

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」を選び、このリポジトリ直下のディレクトリを指定する
4. ツールバーに追加されたアイコンをクリックすると専用タブが開く

## 使い方

1. 開いたタブの textarea に X のツイート URL を1行1件で貼り付ける (`x.com` / `twitter.com` / `mobile.twitter.com` の `/status/<id>/...` 形式。`.mp4` などの直接動画URLもそのまま可)
2. 「追加」ボタンを押すと `chrome.storage.local` に保存され、各ツイートの動画がグリッドに自動再生 (muted/loop) で並ぶ
3. タイル幅の range スライダーでグリッドのタイルサイズを変更できる
4. 各タイルの右上の × で削除、下部のリンクから元ツイートを新規タブで開ける
5. 同じURLを重複して追加しても1件しか保存されない。取得に失敗したツイート (削除済み・非公開など) は「取得不可」と表示される

`index.html` は `file://` で直接開いても textarea とグリッドは表示される (`chrome.storage` が無い場合は `localStorage` にフォールバックする)。
