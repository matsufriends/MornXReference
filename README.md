# MornXReference

X (Twitter) のブックマークから動画・画像を集めて、X の画面内にグリッド状に並べて眺める Chrome 拡張です。

## 導入

1. このリポジトリを clone するか、ZIP をダウンロードして展開します
2. Chrome で `chrome://extensions` を開きます
   - Edge や Brave、Arc など Chromium 系のブラウザでも動きます。その場合はそれぞれの拡張機能ページを開いてください
3. 右上の「デベロッパーモード」を ON にします
4. 「パッケージ化されていない拡張機能を読み込む」を押し、`manifest.json` があるフォルダを選びます
5. x.com を開いているタブがあれば再読み込みします

拡張を更新したときは、`chrome://extensions` で MornXReference の更新ボタンを押してから、x.com のタブを再読み込みしてください。

## 使い方

1. x.com を開くと、左サイドバーの「ポストする」の下に「ギャラリー」ボタンが現れます
2. 押すとブックマークを自動で読み込み、動画と画像がグリッドに並びます。動画は自動で再生されます。2 回目からは前回の一覧をすぐに表示し、新しく増えたブックマークだけを読み込みます
3. 上部のバーで、タイルの大きさ、音の有無、画像と動画の切り替え、文字や日付による絞り込みを変えられます
4. タイルをクリックすると拡大表示になります。「元ポスト」から元の投稿を開けます

## 注意

- X の画面構造に依存しているため、X 側の変更で動かなくなることがあります
- ブックマークが多いと読み込みに時間がかかります
- 削除済みや非公開のポストは表示されません
- ブックマークから外したポストは、上部の「全件読み直し」を押すまで残ります
