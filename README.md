# MornXReference

X (Twitter) のブックマークを自動読み込みして、メディア (動画・画像) をグリッド状に自動再生 (muted/loop) で並べて閲覧する Chrome 拡張。Live2D の WIP リファレンス用。

依存ライブラリ・ビルド工程なし。素の HTML/CSS/JS のみ。

## 読み込み手順

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」を選び、このリポジトリ直下のディレクトリを指定する
4. ツールバーに追加されたアイコンをクリックすると専用タブが開く

## 使い方

1. 開いたタブで「ブックマークを再読み込み」ボタンを押す
2. X のブックマーク一覧タブが自動で開き、最下部までスクロールしながらメディア付きの投稿を収集する (収集中は右下に件数バッジが出る)
3. 収集が終わるとそのタブは自動で閉じ、グリッド表示タブがアクティブになる
4. 各投稿のメディアがタイルとして並び、動画は自動再生 (muted/loop) される。タイル下部のキャプションと「元ポスト」リンクから元の投稿を新規タブで開ける
5. タイル幅の range スライダーでグリッドのタイルサイズを変更できる
6. 再度読み込むと、その時点のブックマークに存在する投稿だけが残り (外れた投稿は消える)、既に取得済みのメディア情報はキャッシュとして再利用される。取得に失敗した投稿 (削除済み・非公開など) は「取得不可」と表示される

`index.html` は `file://` で直接開いてもグリッドは表示される (`chrome.storage` が無い場合は `localStorage` にフォールバックする。ただしブックマーク収集は拡張機能としての読み込みが必要)。
