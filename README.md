# MornXReference

X (Twitter) のブックマークから動画・画像を集めて、X の画面内にグリッド状に並べて眺める Chrome 拡張です。

## 導入

1. このリポジトリを clone するか、ZIP でダウンロードして展開する
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」を ON にする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダ (`manifest.json` があるディレクトリ) を選ぶ
5. x.com を開いているタブがあれば再読み込みする

更新したときは `chrome://extensions` の MornXReference にある更新ボタンを押してから、x.com のタブを再読み込みする。

## 使い方

1. x.com にログインした状態で開くと、左サイドバーの「ポストする」の下に「ギャラリー」ボタンが出る (サイドバーが細い時はアイコンだけ)
2. 押すとブックマーク一覧 (`/i/history`) に移動し、自動スクロールで動画・画像付きのポストを集め始める
3. サイドバーの右側にギャラリーが開き、見つかった順に正方形タイルで並ぶ。動画は自動再生 (ミュート・ループ)
4. 上部の操作
   - `×` : 閉じる
   - スライダー : タイルの大きさ
   - `全部 / 画像 / 動画` : 種別の切り替え
   - 文字入力 : 作者名・本文に含まれる文字で絞り込み
   - 日付 2 つ : 投稿日の範囲で絞り込み (片方だけでも可)
5. タイルをクリックすると拡大表示 (動画は再生コントロール付き)。背景クリックか `Esc` で戻る
6. 各タイルの下の「元ポスト」で元の投稿を新しいタブで開く
7. X 内で別の画面へ移動するとギャラリーは自動で閉じる

配色は X のテーマ (ライト / ダークブルー / ブラック) をそのまま引き継ぐ。

## 仕組み

- `content.js` : x.com 上で動く。ボタンの設置、ブックマーク一覧の自動スクロール収集、ギャラリーの描画
- `background.js` : ポストごとのメディア URL を X の埋め込み用 API (`cdn.syndication.twimg.com`) から取得し、`chrome.storage.local` にキャッシュする
- `lib.js` : URL の正規化やメディア抽出などの純粋関数。`test.mjs` から Node で検証できる

```sh
node test.mjs
```

## 制限・注意

- X の画面構造 (`data-testid` など) に依存しているため、X 側の変更で動かなくなることがある
- 収集はページの自動スクロールで行うため、ブックマークが多いと時間がかかる。スクロールが 3 回続けて伸びなくなったら終了する
- 削除済み・非公開のポストはメディアを取得できないので表示されない
- 埋め込み用 API はログイン不要の公開情報だけを返す。自分のブックマーク一覧そのものは X にログインしたブラウザで表示している内容を読む
