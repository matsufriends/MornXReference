# MornXReference

X (Twitter) のブックマークからメディア (動画・画像) を収集し、ページ内のオーバーレイにグリッド状に自動再生 (muted/loop) で並べて閲覧する Chrome 拡張。Live2D の WIP リファレンス用。

依存ライブラリ・ビルド工程なし。素の JS のみ (専用ページなし)。

## 読み込み手順

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」を選び、このリポジトリ直下のディレクトリを指定する

## 使い方

1. X (x.com / twitter.com) を開くと、左サイドバーのブックマーク項目の下に「ギャラリー」項目が追加される
2. 「ギャラリー」をクリックするとブックマーク一覧に遷移し (または既にブックマーク一覧にいればそのまま)、自動スクロールでの収集が始まる
3. 収集と同時にページ内の全画面オーバーレイが開き、メディア付きの投稿が見つかるたびにタイルとして逐次追加される。動画は自動再生 (muted/loop)、画像はそのまま表示され、タイル下部のキャプションと「元ポスト」リンクから元の投稿を新規タブで開ける
4. 上部の range スライダーでタイルサイズを変更できる
5. 上部の × ボタンでオーバーレイを閉じる (ページ自体の自動スクロールは裏で続いていても影響しない)
6. 一度取得したメディア情報は `chrome.storage.local` にキャッシュされ、同じ投稿を再度開いたときは再フェッチしない
